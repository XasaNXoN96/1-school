# Школа №1 (№1-Maktab), г. Гагарин — сайт и система для сотрудников

Без зависимостей: нужен только **Node.js 22.5+** (используется встроенный `node:sqlite`).

## Запуск

```bash
cp .env.example .env        # при необходимости отредактируйте
npm start                   # http://localhost:3000
```

- Сайт для гостей: `http://localhost:3000/`
- Вход для сотрудников: `http://localhost:3000/panel/`
- При первом запуске `/panel/` предложит создать администратора — это директор (полные права).

### Демо-данные (для проверки)
```bash
DATA_DIR=./data node --disable-warning=ExperimentalWarning scripts/seed-demo.js --yes
npm start
```
Логины (пароль у всех `Demo-2026-School`): `director`, `assistant`, `teacher1`, `teacher2`, `teacher3`.
Демо-данные нужны только для проверки; в рабочей базе их не используйте.

### Telegram-бот
1. Создайте бота у @BotFather, пропишите `TELEGRAM_BOT_TOKEN` в `.env`.
2. Админ: «Пользователи» → «Telegram» → код привязки. Сотрудник отправляет боту `/start КОД`.
3. Кнопки бота: Пришёл / Ушёл (запрашивает геолокацию), Зарплата, Поручения, Уроки сегодня, Мои планы.
4. Радиус и координаты школы: «Настройки» → «Геозона» (кнопка «Взять мои текущие координаты» — нажать, находясь в школе).

## Принятые допущения
- Директор = администратор с полными правами; назначает ассистента (все, кроме директора и других ассистентов).
- Достижения создаются черновиками; на сайте — только после предпросмотра и «Подтвердить и опубликовать». Так же новости.
- Опоздание считается после допуска «grace» (по умолчанию 10 мин); директору и ассистентам приходит уведомление.
- Зарплата = оклад ÷ рабочие дни месяца × (пришёл + уважительно).
- Заморозка и удаление — единственные две операции над аккаунтом. Заморозка блокирует вход, сессии и бота.
- Интерфейс: uz / ru / en. Контент (новости, страницы, достижения) хранится на одном языке — на том, на котором введён.
