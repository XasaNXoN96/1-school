# Школа №1 (№1-Maktab), г. Гагарин — сайт и система для сотрудников

Без зависимостей: нужен только **Node.js 22.5+** (используется встроенный `node:sqlite`).

## Запуск

```bash
cp .env.example .env        # при необходимости отредактируйте
npm start                   # http://localhost:3000
```

- Сайт для гостей: `http://localhost:3000/`
- Вход для сотрудников: `http://localhost:3000/panel/`
- При первом запуске `/panel/` предложит создать администратора — это директор (полные права).

### Демо-данные (для проверки)
```bash
DATA_DIR=./data node --disable-warning=ExperimentalWarning scripts/seed-demo.js --yes
npm start
```
Логины (пароль у всех `Demo-2026-School`): `director`, `assistant`, `teacher1`, `teacher2`, `teacher3`.
Демо-данные нужны только для проверки; в рабочей базе их не используйте.

### Telegram-бот
1. Создайте бота у @BotFather, пропишите `TELEGRAM_BOT_TOKEN` в `.env`.
2. Админ: «Пользователи» → «Telegram» → код привязки. Сотрудник отправляет боту `/start КОД`.
3. Кнопки бота: Пришёл / Ушёл (запрашивает геолокацию), Зарплата, Поручения, Уроки сегодня, Мои планы.
4. Радиус и координаты школы: «Настройки» → «Геозона» (кнопка «Взять мои текущие координаты» — нажать, находясь в школе).

## Проверка присутствия по лицу + геозоне

Включается в панели: «Проверка лица» → «Правила» → «Требовать проверку лица». Пока выключено, работает прежняя отметка (кнопка/геолокация в боте).

**Как работает.** Сотрудник открывает страницу `/checkin` (в Telegram — кнопкой Mini App, в браузере — из кабинета «Моя отметка»). Страница берёт геопозицию, затем просит нейтральное фото и два случайных задания (подмигнуть левым/правым глазом, улыбнуться, повернуть голову). Решение принимает **сервер**: одноразовый токен сессии (3 мин, не раньше 2,5 с), геозона (точность GPS ≤ 100 м, свежесть ≤ 120 с, расстояние ≤ радиуса), лицо (сравнение с эталонными фото сотрудника), «живость» по заданиям, проверка, что лицо не похоже на другого сотрудника, и согласованность кадров. Результат сразу виден сотруднику и администратору.

**Пороги** (панель → «Правила»): совпадение ≤ 0,45 — отметка; 0,45–0,55 — «на проверке» (админ подтверждает/отклоняет); выше — отказ. Пороги живости — `public/js/liveness.js`; сырые метрики каждой попытки хранятся для калибровки.

**Настройка.**
1. `PUBLIC_URL=https://ваш-домен` (HTTPS обязателен для камеры, геолокации и Mini App) и `TELEGRAM_BOT_TOKEN`.
2. Загрузить 2–5 фото каждого сотрудника: «Проверка лица» → «Лица сотрудников».
3. Задать координаты школы и радиус, затем включить «Требовать проверку лица».

**Ограничения.** Подмену GPS приложением-эмулятором из браузера не обнаружить; обход через виртуальную камеру/дипфейк снижен случайными заданиями, одноразовыми токенами, лимитом попыток и просмотром фото-доказательств админом, но не исключён. Пороги живости нужно откалибровать на реальных людях. Модели face-api.js (MIT, ~7 МБ) лежат в `public/vendor/face`; на CPU сервера проверка занимает ~6–8 с.

## Родители, журнал и новые разделы

- **Кабинет родителя** (сайт → «Для родителей»): у каждого ученика личный код (8 символов). Коды: панель → «Родители и рассылки» → «Создать недостающие коды» (есть печать листков). Родитель вводит код на сайте и видит оценки, посещаемость, домашние задания, расписание и сообщения. Тот же код можно отправить Telegram-боту — тогда уведомления приходят в Telegram. Имя бота (без @) укажите в том же разделе, чтобы на сайте работала кнопка.
- **Журнал учителя**: отметка присутствия и оценки с телефона; родители получают уведомление. Учитель может править журнал любого класса, все изменения попадают в журнал действий.
- **Рассылки** родителям (всем или по классу) и сотрудникам; **запись на приём**, **заявки на справки** (печать → «Сохранить как PDF»), **обращения** (в т. ч. анонимные, ответ виден по коду).
- **Кадры**: заявки на отпуск/больничный с одобрением (оплачиваемые дни считаются в зарплате), **замены уроков** (подбор свободных учителей), **расчётные листки** с премиями и удержаниями.
- **Информация**: меню столовой, звонки, подвоз, документы (PDF/Word/Excel) — показываются на сайте.
- **Безопасность** (только директор): журнал входов, вход по одноразовому коду из Telegram (сначала включается проверкой кода; если Telegram недоступен — аварийно запустите сервер с `DISABLE_2FA=1`), резервные копии базы по расписанию. В копию попадает только база; папку `data/uploads` копируйте отдельно. Отправка копии в Telegram по умолчанию выключена: в базе есть хэши паролей и данные лиц.
- PDF делается средствами браузера (кнопка «Печать / PDF»), серверной генерации PDF нет. «Электронная очередь» реализована как запись на приём по времени.

## Принятые допущения
- Директор = администратор с полными правами; назначает ассистента (все, кроме директора и других ассистентов).
- Достижения создаются черновиками; на сайте — только после предпросмотра и «Подтвердить и опубликовать». Так же новости.
- Опоздание считается после допуска «grace» (по умолчанию 10 мин); директору и ассистентам приходит уведомление.
- Зарплата = оклад ÷ рабочие дни месяца × (пришёл + уважительно).
- Заморозка и удаление — единственные две операции над аккаунтом. Заморозка блокирует вход, сессии и бота.
- Интерфейс: uz / ru / en. Контент (новости, страницы, достижения) хранится на одном языке — на том, на котором введён.
